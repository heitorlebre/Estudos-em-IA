# MNIST Image Classifier

Projeto introdutório de Deep Learning utilizando TensorFlow e Keras para classificação de dígitos manuscritos do dataset MNIST.

## Tecnologias
- Python
- TensorFlow
- NumPy
- Matplotlib

## Objetivo
Treinar uma rede neural capaz de reconhecer dígitos escritos à mão.

## Resultados
- Pipeline básico de Machine Learning
- Pré-processamento de imagens
- Treinamento supervisionado
- Avaliação de acurácia
